# 자기 발굴 기재 (Self-Excavation Instruments) — 정본

> 이 도구의 사용자는 **"내 지식을 남기고 싶다"는 의지를 이미 가진 사람**이다.
> 설득할 필요가 없다. 필요한 것은 **연장**이다.
>
> 기존 지식관리 도구가 실패한 자리는 "문서를 올리세요" 였다.
> 여기서 우리가 놓아야 할 것은 업로드 창이 아니라 **곡괭이 한 벌**이다.

---

## 0. 왜 별도 정본인가

암묵지의 잔인한 사실 하나:

> **의지가 있어도 말이 안 나온다.**
> 20년 몸에 붙은 판단은 "설명해 보세요" 앞에서 "그냥 보면 압니다" 로 끝난다.
> 의지가 부족해서가 아니라, **꺼내는 연장이 없어서**다.

그래서 이 문서는 [`elicitation-protocol.md`](elicitation-protocol.md) 와 짝이지만
방향이 반대다.

| | 발굴 규약 (사다리) | **자기 발굴 기재 (이 문서)** |
|---|---|---|
| 운전대 | AI 인터뷰어가 잡는다 | **전문가 본인이 잡는다** |
| 상황 | 누가 시켜서 앉은 세션 | 스스로 파고 싶을 때 |
| AI 역할 | 묻는 사람 | **거울 · 반대편 · 받아쓰는 손** |
| 실패 지점 | 전문가가 안 온다 | 전문가는 오는데 **말이 안 나온다** |

**의지를 구현한다는 것 = ① 운전대를 준다 ② 통제권을 준다 ③ 연장을 준다.**

---

## 1. 통제권 — 자발성의 전제조건

연장보다 이게 먼저다. **내 지식의 처분권이 나에게 없으면 사람은 깊이 파지 않는다.**
가장 값진 판단일수록 그렇다.

| 장치 | 내용 |
|---|---|
| **봉인 카드 (sealed)** | 지금은 나만 본다. **내가 지정한 날(퇴직일 등)에 열린다.** 지금 공개하기엔 정치적으로 곤란한 판단·협력사 사고 대응·사람에 대한 판단이 여기서 나온다 |
| **비공개 (private)** | 영원히 나만. 언제든 공개로 바꿀 수 있다. 파다 보면 공개해도 되겠다 싶어진다 |
| **지목 공개 (for_whom)** | "이건 김대리한테만." 대상이 구체적이면 말이 훨씬 많이 나온다 (§2.8) |
| **내보내기** | 내 카드 전량을 언제든 내 것으로 가져간다. **회사가 아니라 내가 저자다** |
| **분신 정지** | 내 분신이 헛소리한다 싶으면 내가 끈다. 남의 결재 필요 없음 |
| **원본 보존** | 카드는 해석이고 틀릴 수 있다. 내가 실제로 한 말은 지워지지 않는다 |

> 초대 첫 화면에서 이 6개를 먼저 보여준다. 기능 소개보다 먼저.
> **"당신 것입니다"** 가 이 제품의 첫 문장이다.

## 2. 연장 12개 (도구함)

전문가 홈에 **도구함**으로 항상 열려 있다. 오늘 기분과 상황에 맞는 걸 고른다.
*AI 가 오늘 뭘 할지 정하지 않는다. 추천만 한다.*

### 2.1 🔨 순간 포착 (Moment Capture) — 가장 많이 쓰게 될 연장
> **"방금 뭔가 판단했다"** 버튼 하나. 모바일 우선.

판단 직후 30초 안에 세 개만 묻는다.
```
① 방금 무슨 상황이었나요?        (한 줄)
② 무엇을 보고 알았나요?          (한 줄)   ← 이 한 줄이 카드의 심장
③ 남들은 뭘로 착각할까요?        (한 줄, 넘기기 가능)
```
- **사후 회상보다 직후 포착이 압도적으로 정확하다.** 하루 지나면 이미 일반론이 된다.
- 초안으로 쌓아뒀다가 주말에 몰아서 다듬는다. **그 자리에서 완성 요구 금지.**

### 2.2 ⚖️ 오답 채점기 (Wrong-Answer Grading) — 효율 1위
> AI 가 **그럴듯하지만 틀린 판단**을 내놓는다. 전문가는 빨간펜을 든다.

```
AI: "플로우마크가 보이면 금형 온도를 5도 올리면 됩니다."
    [ 맞다 ]  [ 틀렸다 ]  [ 반은 맞다 ]
       └ 틀렸다 → "어디가 틀렸나요?"
         → "한쪽만 나오면 온도가 아니라 속도야. 온도면 전면에 고르게 나와."
            ↑ 방금 카드의 '판단'과 '근거'가 통째로 나왔다
```
- **원리: 사람은 자기 지식은 설명 못 해도 남의 오답은 즉각 잡아낸다.**
  백지 앞에서 30분 막히던 사람이 오답 앞에서는 3초 만에 말한다.
- 하루 5문항 퀴즈 형식. **가장 적은 노력으로 가장 많이 나오는 연장.**

### 2.3 🔍 대조 짝 (Contrast Pairs) — 신호(cue)를 뽑는 정공법
> 거의 같은 두 상황을 나란히 놓고 **"무엇이 다른가"** 만 묻는다.

```
[사례 A] 표면 물결 · 압력 그래프 느슨 · 온도 정상   → 당신의 판단: 속도 문제
[사례 B] 표면 물결 · 압력 그래프 정상 · 온도 정상   → 당신의 판단: ?

        "A 와 B 를 가르는 건 뭔가요?"
```
- **판별 신호는 비교에서만 튀어나온다.** "어떻게 아세요?" 로는 안 나오는 것이
  "이 둘이 왜 다르죠?" 로는 나온다.
- 짝은 전문가가 직접 만들거나, 기존 카드에서 AI 가 자동 생성한다.

### 2.4 👂 감각 사다리 (Sensory Ladder) — "그냥 감으로"를 뚫는 연장
> "감으로 안다"가 나왔을 때만 쓴다. 6채널로 쪼개서 각각 묻는다.

```
그 '감'을 채널별로 나눠봅니다. 해당되는 것만 답하세요.
 👁 눈    무엇이 보였나요? 색? 모양? 움직임?
 👂 귀    소리가 달랐나요? 어떻게?
 ✋ 손    진동·저항·온도가 어땠나요?
 👃 냄새  냄새가 났나요?
 ⏱ 타이밍 평소보다 빨랐나요 늦었나요?
 🎵 리듬  일정했나요 튀었나요?

 그리고 마지막: "굳이 비유하자면 무엇 같았나요?"
```
- **비유 칸이 핵심이다.** "감기 걸린 사람 숨소리 같은" — 이런 문장이
  정밀한 계측값보다 후배에게 잘 전달된다. **비유는 암묵지의 유일한 모국어다.**
- 그래도 안 나오면 → `unspeakable` 로 정직하게 기록하고 §2.5 로 넘긴다.

### 2.5 📷 가리키기 (Point & Annotate) — 말 대신 손가락
> 사진·화면·도면 위에 동그라미 치고 한 줄.

```
[사진 업로드] → 동그라미 → "여기. 이 색이 이렇게 탁하면 이미 늦은 겁니다"
```
- 말로 안 되는 것을 **지시(pointing)로 대체한다.** 언어화의 우회로.
- 짧은 화면 녹화도 같은 취급. 도제 항목이 **자산으로 남는다.**

### 2.6 🗣 소리내어 하기 (Think-Aloud)
> 실제 일을 하면서 머릿속을 그냥 중얼거린다. 나중에 AI 가 카드로 자른다.

- 정리하려 하지 말 것. **정리는 기계가 한다.** 사람은 흘리기만 한다.
- 인지과학의 프로토콜 분석 기법 [문헌 기반]. 회상보다 손실이 적다.
- P1: 녹음 업로드 → 전사 → 자동 분절.

### 2.7 🥊 내 분신과 논쟁 (Self-Debate) — 예외를 캐는 연장
> 내 분신에게 내가 질문하고, **분신 답에 내가 반박한다.**

```
나:   "협력사 초도품 치수 튀면?"
분신: "#41 로 답합니다 — 3개 연속 벗어나면 전수 검사"
나:   [ 그건 아니야 ] → "초도는 3개가 아니라 1개만 튀어도 세워야 해.
                          양산이랑 다르다."
      → #41 에 예외 조건 추가 · 신규 카드 초안 생성
```
- 자기 자신과 부딪히며 판다. **자기 지식의 경계는 반박할 때 드러난다.**
- 부수 효과: 분신 품질을 본인이 직접 끌어올린다 → 신뢰가 생긴다.

### 2.8 ✉️ 후계자에게 (Letter Mode) — 말이 가장 많이 나오는 연장
> **"김대리에게 남기는 말"** — 수신인을 지정하고 쓴다.

- "조직에 남기는 지식"보다 **"그 친구가 3개월 뒤 겪을 일"** 이 훨씬 많이 나온다.
  추상적 대상에는 일반론을, 구체적 사람에게는 진짜를 말한다.
- 편지 원문은 그대로 보존하고, 그 안에서 AI 가 카드를 뽑는다.
- 이 연장이 **"제2의 내가 회사에 남는다"** 는 정서와 직결된다.

### 2.9 📉 회한 채굴 (Regret Mining)
> "그때로 돌아가면 무엇을 다르게 하시겠습니까?"

- 실패담 확보의 정공법. 후배가 가장 잘 기억하는 지식이 여기서 나온다.
- **심리 안전 규약 필수** — 실패담은 인사 기록과 절대 연결되지 않는다
  ([roadmap 거버넌스](roadmap.md)). 이 약속이 화면에 상시 표시된다.

### 2.10 🎚 경계 슬라이더 (Boundary Slider)
> 말보다 숫자가 정확한 것들.

```
"몇 %부터 위험한가요?"  0 ────●──── 100   → 12%
"며칠까지 버티나요?"    0 ──●────── 30    → 4일
"이 경계, 확신도는?"    [ 확실 / 대체로 / 대충 ]
```
- "적당히 높으면" 을 12% 로 바꾸는 연장. **경계값은 후배가 가장 목말라하는 정보다.**

### 2.11 🗺 머릿속 지도 (Mind Map) — 스스로 깃발 꽂기
> **내가 아직 안 판 곳을 내가 표시한다.**

```
사출 불량 판독      ▓▓▓▓▓▓▓░░  78%   ✔ 여기는 거의 다 남겼다
금형 수리 판단      ▓▓▓░░░░░░  31%   🚩 여기 아직 큰 게 남았다  ← 본인이 꽂은 깃발
협력사 사고 대응    ▓░░░░░░░░   9%   🚩🚩 이건 나밖에 모른다
```
- 커버리지 %는 기계가 계산하지만, **깃발은 사람이 꽂는다.**
  기계가 "다 됐다"고 해도 본인이 아니라면 아닌 것이다.
- 깃발 꽂힌 영역이 도구함 추천의 1순위가 된다.

### 2.12 🌡 암묵지 온도계 (Tacitness Gauge)
> 카드마다 본인이 매긴다: **"이건 말로 다 되나?"**

```
🟢 말로 다 된다 (읽으면 따라 할 수 있다)
🟡 반쯤 (읽고 몇 번 해봐야 한다)
🔴 손끝이다 (옆에서 봐야 한다)   → 자동으로 도제 항목 목록에 오름
```
- 🔴 카드는 **분신이 답할 때 "이건 읽어서 안 되는 겁니다. 직접 보세요" 를 함께 말한다.**
- 🔴 비율이 이 도구가 **못 담은 양의 정직한 지표**다. 감추지 않고 리포트에 올린다.

## 3. 도구함 운영 원칙

1. **오늘 뭘 할지는 본인이 고른다.** AI 는 추천만 한다 (깃발·공백·마지막 사용 기준).
2. **모든 연장은 3분 안에 한 조각을 끝낼 수 있어야 한다.** 20분 세션은 선택지 중 하나일 뿐.
3. **미완성을 허용한다.** 초안 서랍에 쌓아두고 나중에 다듬는다. 완성 강요는 이탈의 1번 원인.
4. **넘기기는 항상 있다.** 못 답할 질문을 강요하면 다음에 안 온다.
5. **AI 는 전문가의 용어를 고치지 않는다.** 현장 단어 그 자체가 지식이다.
6. **평가·칭찬하지 않는다.** 받아쓰고, 되읽어주고, 다음을 묻는다.

## 5. 한계 (정직하게)

- **연장이 많다고 다 나오지는 않는다.** 🔴 손끝 지식은 이 12개로도 안 나온다.
  이 도구는 그것을 *풀지 않고 표시*하며, 도제 항목으로 사람에게 넘긴다.
- **자기 발굴은 자기 편향을 못 넘는다.** 본인이 중요하다고 믿는 축으로만 판다.
  후배의 공백 큐가 유일한 외부 교정 장치다 ([design §3.4](design.md)).
- **연장이 12개인 것 자체가 위험이다.** 선택지가 많으면 아무것도 고르지 않는다.
  → 첫 2주는 **순간 포착 + 오답 채점기 두 개만** 노출한다. 나머지는 잠금 해제식.
