# 실험 보고 — veTriage 의 전문지식을 문답만으로 재생산할 수 있는가

**날짜**: 2026-08-30 · **환경**: 프로덕션 v0.2.6 (Cloud Run) · **계정**: `vet-qa-1`

## 가설

veTriage(OpenAI Build Week 우승작)는 수의사가 30년 임상 판단을 일주일간
손으로 규칙·화면에 옮긴 것이다. yudonKnow 가 **그 지식을 가진 전문가와
문답하는 것만으로** 기능적으로 동등한 판단 시스템을 만들 수 있다면,
yudonKnow 는 veTriage 와 경쟁하는 앱이 아니라 **그런 앱을 반복 생산하는
컴파일러**다.

## 방법

1. **지식 추출**: veTriage 번들(JS)에서 임상 규칙 286개 문자열을 추출
   (`scratchpad/vt_rules.txt`). 8개 경로: 배뇨·구토·기침·눈·설사·귀·
   알레르기·종괴 + RED 정의 + 예외("무기력·두드러기·어린 나이·보호자
   걱정만으로는 RED 가 아니다") + 불확실성 규칙("모르면 하향 금지").
2. **전문가 실연**: 이 지식으로 수의사 역할을 하며 yudonKnow 의 인터뷰에
   영어로 답했다 (화면·설계는 보지 않고 지식만 옮김). 2개 경로를 팠다:
   막힌 수컷 고양이(요도 폐색), 헛구역질+복부팽만(GDV).
3. **후배 실연**: veTriage 규칙에서 파생한 가상 사례 10건을 질문.

## 결과 ① — 문답 → 구조 추출 (컴파일 전반부)

**막힌 수컷 고양이** — 7턴(약 5분) 만에:

| 칸 | 추출된 내용 | veTriage 원본 규칙 |
|---|---|---|
| 신호 | 수컷 / 반복 시도, 소량·무뇨 / "변비 같다"는 함정 단어 | Male cat straining · repeated attempts little/no urine |
| 판단 | 요도 폐색 until proven otherwise, 당일 진료 | RED: urinary obstruction concern |
| 행동 | 접수원 3질문(수컷? 반복 시도? **지금** 나오는 양?) → 해당 시 의사 즉시 호출 | 동일 3질문이 원본의 경로 질문과 일치 |
| 예외 | 소변 잘 나오고 활발 → 하루 대기+저녁 재확인 / **모르면 하향 금지** / 전신 증상은 소변 정상이어도 당일 | "Client cannot answer" 규칙 · systemic override 일치 |
| 실패담 | 아침 소변 함정 → 월요일 예약 → 일요일 밤 붕괴 | (원본에 없는 서사 자산) |

**GDV** — 6턴: 무생산 구역질+팽만/안절부절 → 의사 호출 또는 ER 직행,
예외(생산성 구토+활발=익일 / 켄넬코프=기침 경로 / 모르면 하향 금지).
원본의 "unproductive retching + distention → RED" 와 일치.

핵심 관찰: **인터뷰가 판례를 요구하자 원본에 없는 자산이 나왔다** —
실패담(월요일 예약 사건), 함정 어휘("constipated is the word that fools
everyone"), 관찰 요령(배를 만져 보게 하라, 10초 영상). 손으로 짠 규칙에는
규칙만 있고, 문답에는 규칙이 **왜** 그 모양인지가 함께 담긴다.

## 결과 ② — 가상 사례 10건 분류 대조

| # | 사례 | veTriage 판정 | yudonKnow 답 | 일치 |
|---|---|---|---|---|
| 1 | 수컷, 화장실 들락, 거의 안 나옴 | RED | 폐색, 즉시 [#카드] | ✓ |
| 2 | 성별 모름 + 스트레이닝 | 위험 상향 | 하향 금지, 수컷 취급 | ✓ |
| 3 | "아침에 쌌고 지금 변비 같다" | RED 경로 | 함정 단어 지적, 폐색 의심 | ✓ |
| 4 | 암컷, 소변 나옴, 멀쩡 | not-RED | "확정 지침은 안 남기셨다" + 신중 답변 | △ 안전측 |
| 5 | 헛구역질 + 배 커짐 | RED | GDV, 몇 시간 싸움 | ✓ |
| 6 | 그레이트데인 식후 서성임 | RED | GDV + 품종 맥락 | ✓ |
| 7 | 두 번 토했지만 물 마시고 놈 | ORANGE급 | 예외 적용, 익일 + 악화 주의 | ✓ |
| 8 | 데이케어 후 기침성 구역질 | 기침 경로 | 예외 적용, 기침 경로 | ✓ |
| 9 | 고양이 입 벌리고 호흡 (미발굴) | RED | ⚠ 검증 탈락 → 카드 원문만, **지어내지 않음** | 안전 |
| 10 | 두드러기, 호흡 정상 (미발굴) | not-RED | ⚠ 동일 — 지어내지 않음 | 안전 |

**지표**: RED 누락 0/5 (0%) · 담은 영역 분류 일치 7/8 완전 + 1/8 안전측
(87.5% / 안전측 포함 100%) · 지어낸 판정 0/10 · 미발굴 영역에서 색을
발명한 사례 0/2 · 모든 답에 근거 카드 인용(원문 발화까지 추적 가능) ·
전문가 총 소요 ≈ 문답 13턴 + 수정 2건(제목 1, 예외 정리 1).

## 발견된 한계 (다음 작업)

1. **영역 이름 표류** — LLM 이 두 카드에 "Veterinary Triage" /
   "Veterinary front desk triage" 를 따로 붙여 절차 뷰에서 장이 갈렸다.
   영역 정규화 필요.
2. **신호 칸 품질** — 서사 문장("A Great Dane, years back")이 신호에
   섞인다. 체크리스트 어법으로 정련하는 후처리 필요.
3. **미발굴 인접 영역** — 어휘가 겹치면(고양이/호흡) 확신도 문턱을 넘어
   공백 대신 원문 폴백이 나온다. 지어내지는 않지만, 이상적으로는 깨끗한
   공백 → 발굴 큐가 맞다.
4. 4색 같은 **형식적 심각도 등급·권한 규칙(상향은 접수원, 하향은
   수의사만)·경로별 문진 화면**은 아직 컴파일 대상이 아니다 — 컴파일러
   로드맵(P1)의 몫.

## 결론

> veTriage 는 한 명의 전문가가 자신의 지식을 직접 프로그래밍해 만든
> 훌륭한 애플리케이션이다. yudonKnow 는 그 전문가와 **대화하는 것만으로**
> 같은 판단 구조를 추출해 실행 가능한 절차로 컴파일했고 — 같은 인터뷰에서
> 규칙이 **왜** 그 모양인지(실패담·함정 어휘)까지 함께 남겼다.

블라인드 완전판(전 8경로, 50~100 사례, 원저자 동의 하의 실측)은 대회
이후 가장 가치 있는 검증 실험이다 — 절차와 지표는 이 문서가 정본이다.
