# 사용자 동선 (User Flows)

세 명의 사용자가 있고, 각자 **다른 앱을 쓴다고 느껴야 한다.**
전문가에게 "지식 관리 시스템"을 보여주면 그 자리에서 끝난다.

| 역할 | 쓰는 이유 | 첫 화면에서 느껴야 할 것 |
|---|---|---|
| **전문가 (떠나는 사람)** | 보람 · 이름을 남김 | "이건 **내 것**이고, **내가 판다**" |
| **후배 (남는 사람)** | 당장 막힌 걸 푼다 | "선배한테 물어보는 것 같다" |
| **관리자 (HR/팀장)** | 승계 리스크 관리 | "누가 나가면 뭐가 빈다" |

---

## A. 전문가 동선 — "연장은 여기 있습니다. 파는 건 당신입니다"

> 전제: 이 사람은 **이미 남기고 싶어 한다.** 설득 화면은 넣지 않는다.
> 대신 **통제권 → 연장 → 보람** 순서로 준다.

### S0. 첫 화면 — "당신 것입니다" (30초)

기능 소개보다 **통제권**이 먼저 온다. 이걸 뒤로 미루면 깊은 판단은 안 나온다.

```
┌──────────────────────────────────────────────────┐
│  여기 남기는 것은 당신 것입니다.                 │
│   · 지금은 나만 볼 수 있게 (비공개)              │
│   · 내가 정한 날에 열리게 (봉인) — 퇴직일 등     │
│   · 특정 후배에게만 (지목)                       │
│   · 언제든 전량 내보내기                         │
│   · 분신이 헛소리하면 당신이 끕니다              │
│   · 실패담은 인사 기록과 연결되지 않습니다       │
│                              [ 알겠습니다 ]      │
└──────────────────────────────────────────────────┘
```

### S1. 초대 → 영역 지도 (첫 10분, 단 한 번)

```
메일/메신저 링크 ─▶ /expert/onboard
```

묻는 것은 세 가지뿐. **여기서 문서를 요구하면 이탈한다.**

1. **"당신이 없으면 이 팀이 못 하는 일은 뭔가요?"** — 자유 서술 3~5줄
2. AI 가 그걸 **영역 카드 6~10칸으로 쪼개서 보여준다** → 전문가는 체크/수정만
   ("사출 불량 판독" · "금형 수리 판단" · "협력사 품질 사고 대응" …)
3. **말투 프로필** — 자주 하는 말 3개, 절대 하지 말라고 가르치는 것 3개,
   퇴직 예정일. (분신의 어투와 안전 원칙이 여기서 나온다)

> **완료 화면:** "당신의 영역 8칸이 만들어졌습니다. 지금 커버리지 0%.
> 첫 인터뷰 20분이면 12% 가 채워집니다." → 바로 [시작] 버튼

### S1-b. 도구함 첫 대면 — 연장 2개만

첫 2주엔 **순간 포착 + 오답 채점기** 두 개만 보인다. 12개를 다 보여주면
아무것도 고르지 않는다.

```
┌─────────────────────────────┬─────────────────────────────┐
│ 🔨 순간 포착                │ ⚖️ 오답 채점기               │
│ 방금 판단한 게 있나요?      │ 제가 틀린 답을 냅니다.       │
│ 30초, 세 줄이면 됩니다.     │ 빨간펜만 들어주세요.         │
│ [ 지금 남기기 ]             │ [ 5문항 시작 ] ← 3분         │
└─────────────────────────────┴─────────────────────────────┘
    3장 쌓이면 다음 연장이 열립니다 →  🔍 대조 짝 · 👂 감각 사다리
```

### S2. 발굴 세션 (20분 × N회 — 그러나 **본인이 연장을 고른다**)

```
/expert/session/{id}
```

연장에 따라 왼쪽 패널만 바뀌고, 가운데·오른쪽은 항상 같다.
전문가는 **오른쪽을 볼 필요가 없다** (보고 싶을 때만 편다).

```
┌─────────────────────┬──────────────────────┬────────────────────┐
│ 연장 [사다리 ▾]     │  내 답 (말하듯이)    │ 지금 만들어지는 카드│
│                     │                      │                    │
│ "최근 6개월 중,     │  [ 텍스트/음성 ]     │  제목 …            │
│  당신이 없었으면    │                      │  신호 …            │
│  크게 잘못됐을      │  ▸ 다음 질문         │  예외 …            │
│  순간 하나만."      │  ▸ 이건 넘길게요     │  ⚠ 예외가 비었습니다│
│                     │                      │  [승인] [고치기]   │
│ 진행 3/7            │                      │                    │
└─────────────────────┴──────────────────────┴────────────────────┘
```

- 왼쪽 상단 드롭다운으로 **연장을 언제든 바꾼다.** 사다리로 시작했다가
  "감으로 안다"가 나오면 👂 감각 사다리로, 막히면 ⚖️ 오답 채점기로 갈아탄다.
  **운전대는 전문가에게 있다.**
- 사다리 모드의 질문은 [`elicitation-protocol.md`](elicitation-protocol.md) 5단을 따라
  **AI 가 이전 답을 물고 파고든다.** 고정 설문지가 아니다.
- 카드마다 **🌡 암묵지 온도**(🟢 말로 됨 / 🟡 반쯤 / 🔴 손끝)와
  **공개 범위**(공개 / 봉인 / 비공개 / 지목)를 전문가가 그 자리에서 정한다.
  🔴 는 자동으로 도제 항목 목록에 오른다.
- **"이건 넘길게요"** 버튼이 반드시 있어야 한다. 못 넘기게 하면 다음 세션에 안 온다.
- 카드가 완성되면 오른쪽에서 **부족한 칸을 AI 가 지적한다**
  ("예외가 비었습니다 — 이 판단이 안 통하는 경우가 있나요?") → 그게 다음 질문이 된다.
- **세션 종료 화면이 중요하다:**
  > "오늘 카드 4장. 커버리지 12% → 27%.
  >  **이 4장 중 2장은 지금 아무도 모르는 판단입니다.**"

### S3. 내 분신 만나보기 (S2 첫 세션 직후, 강제 1회)

```
/expert/preview
```

전문가가 **자기 분신에게 직접 묻는다.** 이 단계가 없으면 신뢰가 안 생긴다.

- 틀리게 답하면 → 그 자리에서 **[이건 아닙니다]** → 교정이 카드에 반영
- 이 화면에서 전문가는 처음으로 "아 이게 남는 거구나" 를 체감한다.
  **온보딩 이탈이 가장 크게 줄어드는 지점이라 강제 1회로 넣는다.**

### S4. 전문가 홈 (재방문 시 첫 화면)

```
/expert
```

위에서부터 순서가 곧 우선순위다.

```
┌────────────────────────────────────────────────────┐
│ 이번 주 당신의 분신                                │  ← ①보람 (항상 맨 위)
│ 후배 7명이 23번 물었고, 19번을 당신 카드로 답했습니다│
│ 김대리: "#34 로 야간 라인 정지 막았습니다" 2일 전   │
├────────────────────────────────────────────────────┤
│ 🔴 후배가 물었는데 제가 못 답한 것 3건             │  ← ②공백 (행동 유도)
│  · "협력사 초도품 치수 튀면?" 4명이 물음 · 위험 상 │
│    [ 3분이면 답할 수 있습니다 → 답하기 ]           │
├────────────────────────────────────────────────────┤
│ ⚠ 후배가 "안 맞았다" 한 카드 2건 → [확인하기]      │  ← ③교정
├────────────────────────────────────────────────────┤
│ 🗺 머릿속 지도 · 커버리지 41%                      │  ← ④내가 파는 곳
│ ▓▓▓▓▓░░░ 사출 불량 판독 78%                        │
│ ▓░░░░░░░ 협력사 사고 대응 9%  🚩 내가 꽂은 깃발    │
│                                                    │
│ 🧰 도구함  🔨순간포착 ⚖️오답채점 🔍대조짝 👂감각    │  ← ⑤연장 (상시)
│           📷가리키기 🥊논쟁 ✉️후계자 📉회한 🎚경계  │
│  추천: #34 에 '예외'가 비었습니다 → 🥊 분신과 논쟁 │
└────────────────────────────────────────────────────┘
```

**핵심 두 가지:**
1. 재방문 유인은 "인터뷰하세요"가 아니라 **"후배가 당신을 찾았습니다"** 다.
2. 오늘 무엇을 팔지는 **AI 가 정하지 않는다.** 추천은 하되 도구함은 항상 열려 있고,
   깃발과 빈 칸을 근거로 **"이 연장이 맞을 것 같다"** 고 제안만 한다.

### S5. 마지막 날 — 승계 리포트

```
/expert/legacy  →  PDF/문서 내보내기
```

퇴직일에 전문가가 받는 것:

- **유산 카드** — "당신이 남긴 판단 87개, 인용 412회, 도움받은 사람 14명"
- 영역별 커버리지 지도 + **못 담은 것(도제 항목) 목록** — 이건 사람에게 인계
- 후배들이 남긴 감사 메시지 모음
- 본인 보관용 사본 (회사 밖으로 가져갈 수 있는 내 지식의 목차)

> 이 화면은 기능이 아니라 **약속**이다. 첫 초대 메일에서부터 이걸 보여준다.

## B. 후배 동선 — "선배한테 물어보듯이"

### J1. 분신에게 묻기

```
/alter/{expert}   또는  /ask  (누구 분신인지 모를 때 자동 라우팅)
```

```
┌──────────────────────────────────┬─────────────────────────┐
│  홍길동 수석의 분신              │  근거                   │
│  ─────────────────────────────── │                         │
│  Q 플로우마크가 한쪽만 나와요    │  📇 #34 게이트 반대편…  │
│                                  │  ✔ 현장 검증 (보고 3건) │
│  A 금형 온도부터 보지 마세요.    │  2026-03 인터뷰 4회차   │
│    한쪽만 나오면 흐름 선단…      │                         │
│    ① 1단 속도 +8%                │  ⚠ 예외 2가지 있음      │
│    ② 30샷 관찰                   │  · 재생재 30% 초과 시   │
│                                  │  · 겨울 첫 가동 2시간   │
│  ⓘ 이 답은 홍길동 수석의 카드    │                         │
│    2장에서만 나왔습니다.         │  [ 이대로 해봤습니다 ]  │
└──────────────────────────────────┴─────────────────────────┘
```

- **답과 근거가 항상 같이 뜬다.** 근거 없이 뜨는 문장은 하나도 없다.
- 카드에 실패담이 있으면 **접히지 않고 펼쳐진다** ("2019년 이 판단으로 …").
  후배가 가장 필요로 하는 게 그거다.

### J2. 분신이 모를 때 (이 화면이 신뢰를 만든다)

```
┌──────────────────────────────────────────────┐
│  이건 홍길동 수석이 남기지 않은 영역입니다.  │
│  지어내지 않겠습니다.                        │
│                                              │
│  ▸ 수석님께 질문을 전달했습니다 (재직 D-84)  │
│  ▸ 비슷한 영역: 박○○ 책임의 분신 [물어보기] │
│  ▸ 급하면: 홍길동 수석 내선 1234             │
└──────────────────────────────────────────────┘
```

**"모른다"를 잘 말하는 것이 이 제품의 기능이다.** 사내 RAG 챗봇이 죽는
이유가 정확히 여기다.

### J3. 적용 보고 (닻) — 30초, 3번의 탭

답을 쓰고 난 뒤 (또는 다음날 알림):

```
#34 대로 해보셨나요?
 [ 잘 됐다 ]  [ 안 맞았다 ]  [ 아직 ]
   └ 잘 됐다 → "무엇이 좋아졌나요?" 불량률 3.1% → 0.8% (선택)
   └ 안 맞았다 → "무엇이 달랐나요?" → 카드가 contested 로, 전문가 큐로
```

- 이 보고가 **✔ 현장 검증 배지의 유일한 출처**다. 조회수·좋아요는 안 쓴다.
- 보고하면 전문가의 유산 원장에 즉시 뜬다 → **후배의 30초가 선배의 보람이 된다.**

### J4. 내 질문 이력 / 팔로우업

- 내가 만든 공백이 채워지면 **알림이 온다**: "수석님이 그 질문에 답하셨습니다"
- 이게 후배가 이 앱에 다시 오는 이유다.

## C. 관리자 동선 — "누가 나가면 뭐가 비나"

```
/admin
```

### M1. 승계 리스크 보드

```
위험도 = (영역 중요도 × 미커버리지) ÷ 남은 재직일

전문가        영역        커버리지   D-day   리스크
홍길동 수석   사출 판독      78%     D-84    ▓▓░░░  중
이○○ 부장    협력사 사고     9%     D-31    ▓▓▓▓▓  ⚠ 심각
박○○ 책임    설비 예지      54%     D-410   ▓░░░░  저
```

**정렬 기준이 곧 개입 순서다.** "이○○ 부장에게 이번 주 인터뷰 3회 배정" 이
이 화면의 유일한 액션.

### M2. 조직 공백 히트맵

후배 질문이 몰리는데 카드가 없는 영역 = **아무도 모르는 곳.**
이건 퇴직과 무관하게 **지금 당장의 조직 리스크**다.

### M3. 활용 리포트

- 분신 사용량, 검증률(anchored/confirmed), 도제 이관 항목 수
- **주의: 전문가 개인 성과 지표로 쓰지 않는다.** ([design §3.5](design.md))

## D. 첫 4주 도입 동선 (조직 관점)

기능보다 이 동선이 중요하다. B2B 파일럿은 여기서 갈린다.

| 주차 | 하는 일 | 성공 판정 |
|---|---|---|
| **W1** | 전문가 **1명**, 영역 **1개**만. 관리자가 인터뷰 2회 동석 | 카드 8장 승인 |
| **W2** | 후배 3명에게 분신 오픈. 다른 채널로 물어도 "분신에 물어봤어?" 로 되돌림 | 질문 20건 · 공백 5건 |
| **W3** | 공백 5건을 전문가가 채움 → 후배에게 알림 | **채워진 공백 재질문 발생** ← 진짜 신호 |
| **W4** | 적용 보고 수집 → 유산 원장 첫 리포트를 전문가에게 보여줌 | **전문가가 다음 인터뷰를 스스로 요청** |

> W4 의 성공 판정이 이 제품의 PMF 신호다. 관리자가 시켜서 하는 인터뷰는
> 지속되지 않는다. **후배의 질문이 인터뷰를 끌어당길 때** 바퀴가 스스로 돈다.
